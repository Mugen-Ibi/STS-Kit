# 2030年からの電話

音声はStyle-Bert-VITS2、音声認識と返答はGemma 4 E2Bを使うロールプレイです。標準の架空史は[scenarios/japan-2030.md](../scenarios/japan-2030.md)。出来事、制度、団体、人物は創作で、未来予測ではありません。

## 使い方

初回は標準の歴史が有効です。「もしもし、そちらは何年ですか？」「2027年の夏はどうだった？」「未来の仕事はどう変わった？」と話しかけてください。未来側は2030年9月27日。墨田区の地域資料室で働く28歳の朝倉灯と電話がつながる設定です。

「歴史のMarkdownを読み込む」でUTF-8の`.md`を選ぶと、次の会話に反映されます。「読み込んだ歴史を読む」で本文を確認できます。「標準の歴史を保存」から編集用の原稿をダウンロードできます。ファイルは4000文字・16KBまでです。

「未来人と話す」をオフにすると通常のアシスタントに戻り、オンで同じ歴史を再び使います。「標準の歴史に戻す」は同梱原稿に戻します。歴史やモードを変更すると会話履歴を消去します。「新しい会話」は歴史を保ったまま会話のみリセットします。「試聴する」は入力文をそのまま読む機能なので、歴史は影響しません。

## 自分の歴史を書く

自由なMarkdownで構いません。以下の見出しを参考にしてください。

```markdown
# 世界の名前
これはフィクションです。
## 通話の前提
未来側の日時、場所、相手との関係。
## 電話の向こうの人物
名前、一人称、年齢、職業、話し方、身近な思い出。
## 年表
2026年から2030年までの出来事と、その人が体験したこと。
## 2030年の暮らし
技術だけでなく、食事、仕事、交通、悩みなど。
## 分からないこと
決めていない重大事件や未来側の現在より先のこと。
```

## 保存と動作

- 設定はこのブラウザのローカルストレージに保存します。再読み込みや再接続時に復元します。保存を禁止したブラウザでは接続中のみ使えます。会話や録音は保存しません。
- 読み込み先はこのPCのアプリだけです。元ファイルを書き換えず、サーバーの共有設定にも保存しません。開いている接続ごとに別の設定を使えます。
- Markdownは安全なプレーンテキストとして表示し、HTMLやスクリプトを実行しません。音声認識には歴史を渡さず、返答生成時に世界設定として渡します。
- 世界設定を毎回文脈に含め、入力が長いときは古い会話から外して上限に収めます。設定と現在の質問だけでも収まらない場合は、短縮を求めるエラーを表示します。
- モデルは設定に沿うよう指示していますが、固有名詞や細部を取り違える場合があります。創作の整合性が重要な場面は画面の返答も確認してください。
